# Khilare & Associates — Premium Website

This version is redesigned around the supplied reference screenshots:
- Times New Roman typography throughout
- Khilare & Associates logo in the navbar
- Transparent hero navbar that becomes white on scroll
- Dropdown navigation + mobile menu
- Animated hero and page transitions
- Alternating process/timeline UI
- Auto-playing testimonials slider with arrows/dots
- Leadership/team feature and dedicated Team page
- Project/gallery/service pages
- Premium multi-column footer + WhatsApp button
- Responsive desktop/tablet/mobile layouts

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Next.js.

For production:

```bash
npm run build
npm start
```

## Main routes

- `/` Home
- `/studio` About / Studio
- `/team` Our Team
- `/expertise` Services
- `/approach` Process
- `/work` Projects
- `/insights` Gallery
- `/contact` Contact
